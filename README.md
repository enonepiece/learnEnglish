## 🎧 通勤學習法：黃金 5 拍節奏

音訊嚴格依循認知心理學的最佳吸收節奏設計：

```
[1. 中文意象導引] ➔ [2. 慢速單字 × 2] ➔ [3. 慢速生活例句 × 2] ➔ [4. 中文情境解析] ➔ [5. 常速例句 + 3.5秒跟讀留白]
```

1. **耳聽畫面，免看螢幕**：中文導師先解構單字核心意象，引導大腦浮現具體生活畫面。
2. **慢速深化**：單字以 `-30%` 與 `-22%` 慢速雙念，例句以 `-20%` 與 `-14%` 慢速雙念，聽清連音與尾音細節。
3. **中文解說內的英文清晰慢速**：解說中若提及英文詞彙，獨立由母語美師以 `-28%` 慢速發音，絕不含糊帶過。
4. **跟隨留白，大聲跟讀**：常速例句播放完畢後，在 3.5 秒純淨靜音期間開口複誦，鍛鍊發音肌肉記憶。
